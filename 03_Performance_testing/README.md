# Performance Testing

Frontend performance testing for the NYC Ballet Shop website.

Website:
https://nycballetshop.com/

## Tools Used
- SpeedLab
- GTmetrix
- Google Lighthouse

## Included Screenshots
- `SpeedLab.png`
- `GTmetrix.png`
- `Lighthouse.png`

## Main Findings
- Low performance scores
- High LCP values
- CLS/layout shift issues
- Frontend optimization required
