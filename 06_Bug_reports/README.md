# Performance Bug Reports

This folder contains performance testing reports and screenshots collected during website/application analysis.

## Included Reports

- **gtMetrix.png** — GTmetrix performance analysis results
- **lightHouse.png** — Google Lighthouse audit report
- **speedLab.png** — Website speed and performance testing results

## Purpose

The reports in this folder are used to:

- Identify performance issues
- Monitor website optimization
- Analyze loading and rendering metrics
- Track performance improvements
- Document QA testing results

## Metrics Covered

The reports may include:

- Performance Score
- Page Load Time
- Accessibility
- Best Practices
- SEO
- Core Web Vitals
